# Fitness Platform MVP

This is a minimal monorepo for a subscription-based fitness platform MVP.

## Project Structure

- `frontend/`: Next.js, React, TypeScript, Tailwind CSS application
- `backend/`: Node.js, Express, TypeScript application
- `docs/`: Documentation folder

## Running the Application

### Frontend
```bash
cd frontend
npm run dev
```

### Backend
```bash
cd backend
npm run dev
```
